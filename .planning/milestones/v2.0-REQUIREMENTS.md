# Requirements: Device Farm v2.0

**Defined:** 2026-04-15
**Core Value:** QAs e pipelines CI conseguem rodar testes Maestro em emuladores gerenciados automaticamente e acompanhar a execucao em tempo real

## v1 Requirements

Requirements for v2.0 milestone. Each maps to roadmap phases.

### CLI Doctor

- [x] **DOC-01**: `device_farm doctor` verifica se Java/JDK 17+ esta instalado e mostra versao
- [x] **DOC-02**: `device_farm doctor` verifica Android SDK (cmdline-tools, platform-tools, emulator, system-images)
- [x] **DOC-03**: `device_farm doctor` verifica ADB esta acessivel e funcional
- [x] **DOC-04**: `device_farm doctor` verifica Xcode e Command Line Tools instalados
- [x] **DOC-05**: `device_farm doctor` verifica Maestro CLI instalado e versao
- [x] **DOC-06**: `device_farm doctor` verifica ffmpeg instalado
- [x] **DOC-07**: `device_farm doctor` verifica PostgreSQL instalado e rodando
- [x] **DOC-08**: `device_farm doctor` verifica Node.js >= 18
- [x] **DOC-09**: `device_farm doctor` verifica go-ios instalado (para iOS devices)
- [x] **DOC-10**: `device_farm doctor` verifica sim-capture binary built
- [x] **DOC-11**: `device_farm doctor` verifica idb instalado
- [x] **DOC-12**: `device_farm doctor` mostra resumo visual (pass/fail por dependencia)

### CLI Dependencies

- [x] **DEP-01**: `device_farm dependencies` instala Java/JDK via brew
- [x] **DEP-02**: `device_farm dependencies` instala Android SDK components via sdkmanager
- [x] **DEP-03**: `device_farm dependencies` instala Xcode Command Line Tools
- [x] **DEP-04**: `device_farm dependencies` instala Maestro via script oficial
- [x] **DEP-05**: `device_farm dependencies` instala ffmpeg via brew
- [x] **DEP-06**: `device_farm dependencies` instala PostgreSQL via brew
- [x] **DEP-07**: `device_farm dependencies` instala go-ios via brew
- [x] **DEP-08**: `device_farm dependencies` instala idb via brew/pip
- [x] **DEP-09**: `device_farm dependencies` builda sim-capture (swift build)
- [x] **DEP-10**: `device_farm dependencies` mostra progresso e resultado por item

### Device Management

- [x] **DEV-01**: Server usa `@device-stream/android` para boot/shutdown de emuladores Android
- [x] **DEV-02**: Server usa `@device-stream/ios-simulator` para boot/shutdown de simuladores iOS
- [x] **DEV-03**: Device allocation mantem mutex-protected assignment por job
- [x] **DEV-04**: Health check periodico via device-stream (substituindo health checker atual)
- [x] **DEV-05**: Auto-restart de device com falha via device-stream lifecycle

### Recording

- [x] **REC-01**: Gravacao MP4 via scrcpy H.264 stream (Android) do inicio ao fim do teste
- [x] **REC-02**: Gravacao MP4 via ScreenCaptureKit MJPEG (iOS) do inicio ao fim do teste
- [x] **REC-03**: Artefato MP4 associado ao job e acessivel via API existente

## Out of Scope

| Feature | Reason |
|---------|--------|
| Multi-node / cluster | Single-node por enquanto, arquitetura permite expandir |
| Slack/email notifications | Webhook cobre o caso, integracao nativa futuramente |
| Frameworks alem do Maestro | Appium, Espresso, XCTest sao futuros |
| App mobile nativo | Web-first |
| Billing / multi-tenancy | Nao e necessario para uso interno |
| Appium drivers install | Appium integration (M005) pausado neste milestone |
