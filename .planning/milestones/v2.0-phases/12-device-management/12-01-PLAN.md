    **Step 2: Create DeviceStreamIosDriver (GREEN)**
    Create `server/pool/ios/device-stream-driver.ts`:

    ```typescript
    import { IOSSimulatorManager } from '@device-stream/ios-simulator';
    import { execFile } from 'node:child_process';
    import { promisify } from 'node:util';
    import type { DeviceDriver, DeviceConfig, IosDeviceConfig, BootOptions, BootResult } from '../types.js';

    const execFileAsync = promisify(execFile);
    ```

    This is a PURE wrapper -- all lifecycle delegated to IOSSimulatorManager:

    1. **Constructor**: Creates `new IOSSimulatorManager({ bootTimeout: 120_000 })`. Stores reference.
    2. **create(name, config)**: Casts config to IosDeviceConfig. Calls `manager.createDevice({ platform: 'ios', name, deviceType: 'com.apple.CoreSimulator.SimDeviceType.' + config.device_type, osVersion: 'com.apple.CoreSimulator.SimRuntime.' + config.runtime })`. Stores UDID mapping `name -> device.id`. Returns `device.id` (UDID).
    3. **boot(emulatorId)**: Calls `manager.startDevice(emulatorId)`. Returns `{ port: 0, pid: 0 }` (iOS uses UDIDs, not ports/PIDs -- PoolManager handles this gracefully already).
    4. **shutdown(emulatorId)**: Calls `manager.stopDevice(emulatorId)`. Wraps in try/catch (already-stopped is not an error).
    5. **isHealthy(emulatorId)**: Calls `manager.getDevice(emulatorId)`. Returns `device?.status === 'ready'`. Returns false if device is undefined.
    6. **cleanup(emulatorId)**: For between-job cleanup (fast): calls `manager.stopDevice(emulatorId)` then `execFileAsync('xcrun', ['simctl', 'erase', emulatorId])`. Does NOT call `deleteDevice()` (that's slow -- full re-creation). The erase approach resets the simulator to factory state without destroying it.

    Export the class. Use `.js` extensions on all relative imports.
