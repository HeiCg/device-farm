```typescript

  jobId: string,
  outputPath: string,
  platform: Platform,
  deviceSerial: string,
  services: PlatformServices,
): Promise<void>
```

Implementation:
- If platform is 'android': assert `services.scrcpyService` exists (throw Error `'ScrcpyService required for Android recording'`), create `new H264FrameSource(services.scrcpyService, deviceSerial)`
- If platform is 'ios': assert `services.captureService` exists (throw Error `'CaptureService required for iOS recording'`), create `new MJPEGFrameSource(services.captureService, deviceSerial)`
- Create `new RecordingSession()`
- Build config: `{ outputPath, codec: platform === 'android' ? 'h264' : 'mjpeg', framerate: 30 }`
- Call `await session.start(config, frameSource)`
- Store `{ session, source: frameSource, jobId }` in `this.recordings` Map keyed by jobId
- Log info with jobId, platform, outputPath

7. **stopRecording method signature:**
```typescript
async stopRecording(jobId: string): Promise<RecordingResult | null>
```

Implementation:
- Get entry from map, return null if not found
- Call `const result = await entry.session.stop()`
- Delete from map
- Log info with jobId, duration, frameCount from result
- Return result

8. **killRecording method:** Same name, sync void. Get entry, if exists call `entry.session.stop()` (fire-and-forget, catch errors), delete from map, log.

9. **isRecording method:** Same as before, check map has key.

Remove all old ffmpeg spawn code, old RecordingEntry type, old imports of child_process/stream. The RecordingSession handles ffmpeg internally.

Note: ProcessTracker integration is skipped for now -- RecordingSession manages its own ffmpeg lifecycle with 5s timeout + SIGKILL escalation. The processTracker parameter is kept in the constructor for backward compatibility but not used in this version.
