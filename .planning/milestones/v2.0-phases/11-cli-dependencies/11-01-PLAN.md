Create `cli/cmd/dependencies.go` in package `cmd` with the following structure:

**1. Types and registry:**

```go
type dependency struct {
    Name    string
    Check   func() []checkResult  // returns slice (Android SDK returns multiple)
    Install func() error
}

type installResult struct {
    Name   string `json:"name"`
    Status string `json:"status"`
    Detail string `json:"detail,omitempty"`
}
```

Define `var installers = []dependency{...}` with exactly 9 entries:

| Name | Check | Install |
|------|-------|---------|
| Java/JDK | `checkBinaryVersion("java", "-version", 17, parseJavaVersion)` | `brewInstall("openjdk@17")` |
| Android SDK | `checkAndroidSDK()` | Custom: brew cask android-commandlinetools + set ANDROID_HOME + `yes \| sdkmanager` for platform-tools, emulator, platforms;android-35, system-images;android-35;google_apis_playstore;arm64-v8a |
| Xcode CLI Tools | `checkXcode()` | Custom: softwareupdate non-interactive (touch trigger file, parse `softwareupdate -l`, install via `softwareupdate -i`) |
| Maestro | `checkBinary("maestro", "--version")` | `runStreamed("bash", "-c", "curl -fsSL \"https://get.maestro.mobile.dev\" \| bash")` |
| ffmpeg | `checkBinary("ffmpeg", "-version")` | `brewInstall("ffmpeg")` |
| PostgreSQL | `checkPostgres()` | `brewInstall("postgresql@16")` then `brew services start postgresql@16` |
| go-ios | `checkBinary("go-ios", "version")` | `brewInstall("go-ios")` |
| idb | `checkBinary("idb_companion", "--version")` | `brewTapInstall("facebook/fb", "idb-companion")` |
| sim-capture | `checkBinary("sim-capture", "--version")` | Custom: `cd ../device-stream && npm run build:sim-capture` with fallback warning if dir not found |

**2. Helper functions:**

- `checkBrewInstalled() error` -- uses `exec.LookPath("brew")`, returns error with install instructions if missing
- `runStreamed(name string, args ...string) error` -- creates subprocess with StdoutPipe + merged Stderr, bufio.Scanner line-by-line output indented with 4 spaces, Wait() AFTER scanner drain
- `brewInstall(formula string) error` -- runs `brew install {formula}` with `HOMEBREW_NO_AUTO_UPDATE=1` env var via runStreamed
- `brewTapInstall(tap, formula string) error` -- runs `brew tap {tap}` then `brew install {formula}`
- `buildInstallList(checks []checkResult, deps []dependency) []dependency` -- returns deps whose check has any "fail" status

**3. Install functions with pitfall avoidance:**

Android SDK installer must:
- First run `brew install --cask android-commandlinetools` with HOMEBREW_NO_AUTO_UPDATE=1
- Determine ANDROID_HOME: `$(brew --prefix)/share/android-commandlinetools`
- Set `os.Setenv("ANDROID_HOME", androidHome)` for current process
- Accept licenses: `bash -c "yes | sdkmanager --licenses"`
- Install components: `bash -c "yes | sdkmanager \"platform-tools\" \"emulator\" \"platforms;android-35\" \"system-images;android-35;google_apis_playstore;arm64-v8a\""`
- Print message telling user to add ANDROID_HOME to shell profile

Xcode CLT installer must:
- Touch `/tmp/.com.apple.dt.CommandLineTools.installondemand.in-progress`
- Run `softwareupdate -l` and parse for "Command Line" entry
- Run `softwareupdate -i {pkg} --verbose` via runStreamed
- Defer remove of trigger file
- If no package found, fallback to `xcode-select --install` with message that GUI dialog will appear

PostgreSQL installer must:
- `brewInstall("postgresql@16")` then `exec.Command("brew", "services", "start", "postgresql@16")` with HOMEBREW_NO_AUTO_UPDATE=1

sim-capture installer must:
- Check if `../device-stream` directory exists
- If yes: `runStreamed("npm", "run", "build:sim-capture")` with cwd set to `../device-stream`
- If no: return error with message "device-stream repo not found at ../device-stream"

**4. Orchestrator (`runDependencies`):**

1. Call `checkBrewInstalled()` -- fail early if brew missing
2. Run all doctor checks (same order as doctor.go, excluding server check)
3. Call `buildInstallList` to get failed dependencies
4. If none failed: print "All dependencies already installed." in green, exit 0
5. Print "Found {N} missing dependencies:" with list
6. For each missing dependency:
   a. Print "{icon} Installing {name}..." in bold
   b. Call install function
   c. Track result as installResult with status "installed" or "failed"
   d. Print result (green checkmark + "done" or red X + error message)
7. Re-run all doctor checks to verify
8. Print summary: "Installed: N, Failed: N, Already present: N"
9. If any install failed, return error (non-zero exit)

**5. JSON output:**

If `JSONOutput` is true, skip all colored output. After orchestration, encode `[]installResult` as JSON to stdout.

**6. Cobra command registration:**

```go
var dependenciesCmd = &cobra.Command{
    Use:   "dependencies",
    Short: "Install missing dependencies detected by doctor",
    Long:  "Runs doctor checks and automatically installs any missing dependencies using brew, sdkmanager, or official install scripts.",
    RunE:  runDependencies,
}

func init() {
    rootCmd.AddCommand(dependenciesCmd)
}
```
