# Runbook: sim-capture-private (SimulatorKit Private Bridge)

## Purpose
The `sim-capture-private` daemon replaces ScreenCaptureKit for iOS Simulator capture in `@device-stream/ios-simulator`. It uses Apple's private `SimulatorKit` and `CoreSimulator` frameworks to receive IOSurface frames directly from the simulator backboard process — bypassing the TCC permission prompt and eliminating compositor latency.

## Prerequisites
- macOS 13+ on Apple Silicon (arm64). The bridge does NOT support Intel Macs.
- Xcode 15.4+ installed (Xcode-select set, or `DEVELOPER_DIR` env set).
- `xcodegen` installed: `brew install xcodegen`.
- An iOS simulator booted (`xcrun simctl boot <UDID>`).

## Install
```
cd device-farm
npm install            # postinstall hook builds sim-capture-private on darwin/arm64
# OR build manually:
bash device-stream/scripts/build-sim-capture-private.sh
ls -l device-stream/bin/sim-capture-private   # should exist + +x
```

## Verify (smoke)
```
device-stream/scripts/smoke-sim-private.sh <UDID>
# Expects: SMOKE: OK, exit 0
```

## Verify (probe — symbol resolution only)
```
device-stream/bin/sim-capture-private --probe <UDID>
# Expects: "OK: 8/8 symbols resolved", exit 0
```

If the probe fails with `MISSING: <role>`, the local Xcode version has drifted Apple's mangled Swift symbol layout. See §Troubleshooting.

## Configuration

| Env var | Effect |
|---------|--------|
| `DEVICE_STREAM_SIM_PRIVATE=0` | Disable the private bridge; fall back to ScreenCaptureKit (`sim-capture-avcc`) |
| `DEVICE_STREAM_SIM_PRIVATE=1` | Force the private bridge (default behavior) |
| `DEVELOPER_DIR` | Override path to Xcode (e.g., `/Applications/Xcode_16.0.app/Contents/Developer`) |
| `DEVICE_STREAM_SKIP_BUILD=1` | Skip native build on `npm install` (postinstall no-op) |

## Manual verification: zero TCC prompt (SIM-PRIV-01)

This requires a fresh macOS user account to validate cleanly.

1. Create a fresh test user: `System Settings → Users → +`.
2. Switch to the new user. DO NOT pre-grant any Screen Recording permission.
3. From a terminal in that user: clone the repo, `npm install`, `device-farm run --platform ios <flow>`.
4. Verify: **no system permission prompt appears** for Screen Recording.
5. Verify: a job completes with frames streamed to the dashboard.

If a prompt appears, the daemon spawn failed and the fallback path engaged. Check `~/Library/Logs/...` and re-run with `DEVICE_STREAM_SIM_PRIVATE=1 NODE_DEBUG=stream` to surface diagnostics.

## Troubleshooting

### Probe fails with `MISSING: SimDevice.screenAdapter.getter`
The Swift mangled symbol changed in this Xcode release. Two options:
1. Set `DEVICE_STREAM_SIM_PRIVATE=0` (fall back to ScreenCaptureKit) and file an issue.
2. Update `kDSCriticalSymbols` in `device-stream/native-servers/sim-capture-private/Sources/Bridge.mm` with the new mangled prefix; re-run `--probe` to confirm. See `32-RESEARCH.md` §Symbol resolution for the trie walker behavior.

### Daemon spawn fails with `EACCES`
The helper is unsigned. macOS Gatekeeper may quarantine it on first run. Run:
```
xattr -d com.apple.quarantine device-stream/bin/sim-capture-private || true
```

### `surfacesChanged` callback never fires (no frames in 10s)
Open Question #1 in `32-RESEARCH.md`: SimulatorKit may require `activateDisplayIfNeeded` (which needs an offscreen NSWindow host) on some configurations. Workaround: fall back via `DEVICE_STREAM_SIM_PRIVATE=0` and file an issue with the Xcode version + macOS version.

### Build fails with `Framework SimulatorKit not found`
- Check `DEVELOPER_DIR` points to a real Xcode install (NOT Command Line Tools): `xcode-select -p`.
- Run `sudo xcode-select -s /Applications/Xcode.app/Contents/Developer`.

2. `device-stream/scripts/smoke-sim-private.sh` — replace Wave 0 stub:

```bash
#!/usr/bin/env bash
# Smoke: probe + capture 30 frames + clean teardown.
# Usage: smoke-sim-private.sh <UDID>
set -euo pipefail

UDID="${1:-}"
if [[ -z "$UDID" ]]; then echo "usage: smoke-sim-private.sh <UDID>" >&2; exit 64; fi

SCRIPT_DIR="$(cd "$(dirname "${BASH_SOURCE[0]}")" && pwd)"
DEVICE_STREAM_DIR="$(cd "$SCRIPT_DIR/.." && pwd)"
BIN="$DEVICE_STREAM_DIR/bin/sim-capture-private"
SOCK="/tmp/device-stream-sim-${UDID,,}.sock"
TMPLOG="$(mktemp)"

if [[ ! -x "$BIN" ]]; then echo "smoke: binary not built at $BIN — run build-sim-capture-private.sh" >&2; exit 1; fi

# 1) probe
if ! "$BIN" --probe "$UDID" | grep -qE "^OK: 8/8 symbols resolved$"; then
  echo "smoke: probe failed for $UDID" >&2; exit 2
fi

# 2) ensure sim booted
xcrun simctl boot "$UDID" 2>/dev/null || true
xcrun simctl bootstatus "$UDID" -b
sleep 2

# 3) spawn daemon
rm -f "$SOCK"
"$BIN" --udid "$UDID" --socket "$SOCK" 2>"$TMPLOG" &
DAEMON_PID=$!
trap "kill $DAEMON_PID 2>/dev/null || true; rm -f $SOCK $TMPLOG" EXIT

# Wait for socket
for i in {1..50}; do test -S "$SOCK" && break; sleep 0.1; done
if ! test -S "$SOCK"; then
  echo "smoke: socket never appeared at $SOCK" >&2
  cat "$TMPLOG" >&2 || true
  exit 3
fi

# 4) read 30 frames via nc -U; count [4-byte BE length][1-byte kind] frames
nc -U "$SOCK" | python3 -c "
import sys, struct
buf = b''
frames = 0
while frames < 30:
  chunk = sys.stdin.buffer.read(4096)
  if not chunk: break
  buf += chunk
  while len(buf) >= 4:
    length = struct.unpack('>I', buf[:4])[0]
    if length == 0 or length > 16*1024*1024:
      sys.exit('smoke: invalid length ' + str(length))
    if len(buf) < 4 + length: break
    frames += 1
    buf = buf[4+length:]
sys.exit(0 if frames >= 30 else 'smoke: only ' + str(frames) + ' frames read')
" &
NC_PID=$!

# Allow up to 30s for 30 frames at 30fps (~1s steady state + 5s warmup buffer)
if ! wait $NC_PID; then
  echo "smoke: failed to read 30 frames in time" >&2
  cat "$TMPLOG" >&2 || true
  exit 4
fi

# 5) clean shutdown
printf '\x00\x00\x00\x01\xc9' | nc -U "$SOCK" -q 1 2>/dev/null || true
kill "$DAEMON_PID" 2>/dev/null || true

echo "SMOKE: OK"
exit 0
```
