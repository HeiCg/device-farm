- `job.log` fires from `job-service.ts` on each `onStdoutLine` or `onCommandStatus` callback (10-100/sec during active job). - `job.step` fires on each `onFlowStart` and `onFlowResult` callback (10-50/job typical). persisted:false (derivable from `jobSteps` DB table).
