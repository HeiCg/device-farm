**cli/cmd/analyze.go:**
Create Cobra subcommand:
```go
func newAnalyzeCmd() *cobra.Command {
  var outputFormat string
  var uploadBuildId string
  var serverURL string

  cmd := &cobra.Command{
    Use:   "analyze <ipa-or-app>",
    Short: "Extract static screen skeleton from an iOS .ipa or .app",
    Args:  cobra.ExactArgs(1),
    RunE: func(cmd *cobra.Command, args []string) error {
      payload, err := analyzeIPA(args[0])
      if err != nil { return err }
      if outputFormat == "markdown" {
        return renderMarkdown(payload, cmd.OutOrStdout())
      }
      enc := json.NewEncoder(cmd.OutOrStdout())
      enc.SetIndent("", "  ")
      if err := enc.Encode(payload); err != nil { return err }
      if uploadBuildId != "" {
        return uploadToServer(serverURL, uploadBuildId, payload)
      }
      return nil
    },
  }
  cmd.Flags().StringVar(&outputFormat, "format", "json", "json|markdown")
  cmd.Flags().StringVar(&uploadBuildId, "upload-to-build", "", "build id to attach the analysis to")
  cmd.Flags().StringVar(&serverURL, "server", "http://localhost:3000", "server base URL for upload")
  return cmd
}
```

`analyzeIPA(path)` pipeline:
1. Unzip `.ipa` to TempDir using `archive/zip` (it's just a zip). Find `Payload/*.app/`.
2. Parse `Info.plist` (binary or XML) — use `howett.net/plist` if you want a Go plist parser OR shell to `/usr/bin/plutil -convert json -o - <plist>` and json.Unmarshal (Pitfall 7: also try JSON parse if plutil fails). Extract `CFBundleIdentifier`, `CFBundleName`, `CFBundleShortVersionString`, `CFBundleExecutable`, `CFBundleURLTypes -> CFBundleURLSchemes`, `MinimumOSVersion`.
3. Locate executable at `Payload/*.app/<CFBundleExecutable>`.
4. Call `macho.ParseObjCClasslist(execPath)` -> `[]ObjCClass`.
5. Call `macho.ParseSwift5Types(execPath)` + `macho.DemangleBatch(mangledNames)` -> Swift type names.
6. Locate `Payload/*.app/main.jsbundle` if exists. Call `macho.IsHermes(path)`; if hermes, call `macho.ExtractHermesScreens(path)`.
7. Apply `macho.ClassifyName` to each candidate; collect screens grouped by source.
8. Build payload matching `skeletonPayloadSchema` (37-BRIEF.md output JSON shape).
9. Populate `deep_link_entries` from `CFBundleURLSchemes`; mark `is_oauth_callback` if scheme matches `^https?$` OR appears in OAuth provider list (just `googleusercontent`, `fb*`, `twitter*`, `linkedin*` heuristic — port from app-explorer).
10. Populate `known_gaps[]` with any extraction failure descriptions.

Register in `cli/cmd/root.go`: `RootCmd.AddCommand(newAnalyzeCmd())`.

<script lang="ts">
  import type { components } from '$lib/api/generated-types';
  type Payload = components['schemas']['Analysis']['payload'];

  let { payload, buildId }: { payload: Payload; buildId: string } = $props();

  // Group candidate_screens by module for the primary table.
  const groupedByModule = $derived.by(() => {
    const groups = new Map<string, typeof payload.candidate_screens>();
    for (const screen of payload.candidate_screens ?? []) {
      const key = screen.module ?? '(no module)';
      if (!groups.has(key)) groups.set(key, []);
      groups.get(key)!.push(screen);
    }
    return [...groups.entries()].sort(([a], [b]) => a.localeCompare(b));
  });

  const confidenceClass = (c: 'high' | 'medium' | 'low') =>
    c === 'high' ? 'bg-green-100 text-green-800'
    : c === 'medium' ? 'bg-yellow-100 text-yellow-800'
    : 'bg-gray-100 text-gray-700';
