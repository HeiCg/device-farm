    **Wizard state machine** (PairingWizard.svelte):
    ```typescript
    type WizardState =
      | { kind: 'idle' }
      | { kind: 'starting' }
      | { kind: 'awaiting-scan'; sessionId: string; qrDataUrl: string; pin: string; expiresAt: number }
      | { kind: 'pairing'; sessionId: string; host: string; port: number }
      | { kind: 'connecting'; sessionId: string; deviceName: string }
      | { kind: 'done'; deviceId: string; deviceName: string }
      | { kind: 'error'; reason: string; canRetry: boolean };

    let state = $state<WizardState>({ kind: 'idle' });
    let ws: WebSocket | null = null;
    ```

    Transitions:
    - `state.kind === 'idle'` renders PairingScanStep with `onStart` button → calls `startPairing()`
    - `startPairing()`:
      - `state = { kind: 'starting' }`
      - `const res = await fetch('/api/devices/pair/start', { method: 'POST' })`
      - On success: `state = { kind: 'awaiting-scan', sessionId, qrDataUrl, pin, expiresAt: Date.now() + ttlSeconds*1000 }`
      - Open WS: `ws = new WebSocket(\`${WS_PROTO}://${location.host}/api/devices/pair/stream?sessionId=${sessionId}\`)`
      - `ws.onmessage` parses frame; switch on `payload.type`:
        - `paired` → `state = { kind: 'pairing', ... }`
        - `connecting` → `state = { kind: 'connecting', ... }`
        - `done` → `state = { kind: 'done', ... }`; close WS
        - `error` → `state = { kind: 'error', reason, canRetry: true }`; close WS
      - On failure: `state = { kind: 'error', reason: 'start-failed', canRetry: true }`
    - `cancel()`:
      - If `state.kind` has `sessionId`, fetch `/api/devices/pair/cancel` with `{ sessionId }`
      - Close `ws`
      - `state = { kind: 'idle' }`
    - On unmount: same cleanup as `cancel()` if not in `done` or `idle` state
