### 🚧 v3.0 Spec-Driven Architecture (In Progress)

**Milestone Goal:** Refactor server + CLI + web for spec-driven (Zod everywhere) and event-driven (typed bus + pg-boss) architecture so the codebase is readable and maintainable by LLMs. No new user features.

**Pillars (locked):**
1. Zod at every boundary (API, WS, events, DB rows, config) — TS types inferred
2. In-process typed event bus per module (`events.ts`)
3. pg-boss as the single durable queue (replaces in-memory + `node-cron`)
4. Correlation IDs + append-only `events` table for traceability
5. LLM-first modules (`MODULE.md` + barrel `index.ts` + `events.ts` + tests-as-spec)

**Strategy:** module-by-module migration. Foundations first, pilot (`hooks`) second, then build/ops hygiene, then module refactors in dependency order, keystone (`jobs`) late, consumers (`CLI`, `web`) last.
