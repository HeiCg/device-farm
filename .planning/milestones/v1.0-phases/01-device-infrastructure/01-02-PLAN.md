    - Device.allocate() transitions from Idle to Allocated and sets currentJobId

       - toInfo() method returning DeviceInfo snapshot.

<task type="auto" tdd="true">
  <name>Task 2: Android emulator driver + iOS simulator driver</name>
  <files>
    server/pool/android/avd.ts, server/pool/android/emulator.ts,
    server/pool/ios/simulator.ts,
    server/pool/android/__tests__/emulator.test.ts,
    server/pool/ios/__tests__/simulator.test.ts
  </files>
  <behavior>
    - AndroidEmulatorDriver.create() calls avdmanager to create AVD with correct flags for ARM64
    - AndroidEmulatorDriver.boot() spawns emulator with -no-window -no-audio -no-boot-anim -gpu swiftshader_indirect flags, then waits for sys.boot_completed=1 (trimmed)
    - AndroidEmulatorDriver.shutdown() kills process group (-pid)
    - AndroidEmulatorDriver.isHealthy() returns true when adb shell getprop dev.bootcomplete returns "1"
    - AndroidEmulatorDriver.cleanup() sends snapshot restore command via emulator console (telnet), falls back to emulator restart on failure
    - IosSimulatorDriver.create() calls xcrun simctl create with device type and runtime, returns UDID
    - IosSimulatorDriver.boot() calls xcrun simctl boot + bootstatus, handles "already booted" gracefully
    - IosSimulatorDriver.shutdown() calls xcrun simctl shutdown
    - IosSimulatorDriver.isHealthy() checks device appears as Booted in simctl list devices -j
    - IosSimulatorDriver.cleanup() calls xcrun simctl shutdown then erase
  </behavior>
  <action>
    1. Create server/pool/android/avd.ts:
       - ensureAvdExists(name, config): Checks if AVD exists (emulator -list-avds). If not, creates with avdmanager: `avdmanager create avd -n {name} -k "system-images;android-{api_level};google_apis;arm64-v8a" -d {device_profile} --force`. Uses execFile (NOT exec).
       - listAvds(): Returns list of existing AVD names.

    2. Create server/pool/android/emulator.ts:
       - AndroidEmulatorDriver implementing DeviceDriver.
       - create(): calls ensureAvdExists, returns AVD name as emulatorId.
       - boot(avdName): spawns `emulator -avd {name} -no-window -no-audio -no-boot-anim -gpu swiftshader_indirect -port {port}` with detached:true. Runs adb wait-for-device then polls sys.boot_completed with .trim() (PITFALL: carriage returns). Returns pid. Port assigned from sequential pool (5554, 5556, 5558...) to avoid collision (PITFALL 2).
       - shutdown(avdName): kills process group via process.kill(-pid, 'SIGTERM'). Wait 5s, then SIGKILL if still alive.
       - isHealthy(avdName): adb -s emulator-{port} shell getprop sys.boot_completed, returns true if trimmed output === '1'.
       - cleanup(avdName): Connect to emulator console (telnet localhost:{consolePort}), send auth token, send "avd snapshot load clean_snapshot". On failure, fall back to full restart. Per RESEARCH open question 1.

    3. Create server/pool/ios/simulator.ts:
       - IosSimulatorDriver implementing DeviceDriver.
       - create(name, config): xcrun simctl create {name} {device_type} {runtime}, returns UDID.
       - boot(udid): xcrun simctl boot {udid} (handle "already booted" error gracefully per PITFALL 3). Then xcrun simctl bootstatus {udid} -b with timeout.
       - shutdown(udid): xcrun simctl shutdown {udid}, ignore error if already shut down.
       - isHealthy(udid): Parse xcrun simctl list devices -j, find device by UDID, check state === 'Booted'.
       - cleanup(udid): shutdown then xcrun simctl erase {udid}.

    4. Write tests mocking execFile for both drivers. Test the edge cases: ADB carriage return trimming, "already booted" error handling, timeout on boot detection, shutdown of already-dead process (ESRCH handling).
  </action>
  <verify>
    <automated>npx vitest run server/pool/android/__tests__/emulator.test.ts server/pool/ios/__tests__/simulator.test.ts --reporter=verbose</automated>
  </verify>

    - iOS driver creates simulators, boots with bootstatus, handles already-booted, erases for cleanup
    - Both drivers implement DeviceDriver interface
    - Edge cases (carriage returns, already booted, ESRCH) are handled
    - All tests pass
  </done>
