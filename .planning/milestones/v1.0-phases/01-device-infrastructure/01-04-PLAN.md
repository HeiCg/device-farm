  <name>Task 1: Health checker with exponential backoff recovery</name>
  <files>
    server/pool/health-checker.ts,

  </files>
  <behavior>
    - Health check calls driver.isHealthy() for every non-offline device in parallel
    - Healthy device: no action, failure count stays 0
    - Unhealthy device (1st failure): restart attempt after 5s delay
    - Unhealthy device (2nd failure): restart attempt after 15s delay
    - Unhealthy device (3rd failure): full wipe + restart attempt after 45s delay
    - After 3rd failure still unhealthy: device transitions to Offline, logged as error
    - Device in Running state that fails health check: device transitions to Error immediately (no restart -- job fails with infra error)
    - Offline device is skipped by health checker
    - Health check interval is configurable (default 30s)
    - start()/stop() control the periodic interval
  </behavior>
  <action>
    1. Create server/pool/health-checker.ts:
       - HealthChecker class with constructor(poolManager, processTracker, logger).
       - Private failureCounts: Map of deviceId to number.
       - Private BACKOFF_DELAYS = [5000, 15000, 45000] (exponential: 5s, 15s, 45s).
       - Private MAX_RETRIES = 3.
       - checkAll(): Gets all devices from pool manager. Filters out Offline. Runs Promise.allSettled() calling checkDevice() for each.
       - checkDevice(device): Calls driver.isHealthy(device.emulatorId).
         - If healthy: reset failure count to 0.
         - If unhealthy and device is Running: transition to Error immediately, log "Running job on device {name} failed -- infrastructure error". Do NOT restart (per user decision: "fail immediately with infrastructure error message").
         - If unhealthy and device is Idle/Booting/etc: increment failure count.
           - If failures <= MAX_RETRIES: wait BACKOFF_DELAYS[failures-1], then attempt restart. On 3rd attempt, do full wipe (driver.shutdown + driver.cleanup) before reboot.
           - If failures > MAX_RETRIES: transition to Offline, log error.
       - restartDevice(device, fullWipe): Kill process group, if fullWipe call driver.cleanup first, then driver.boot(). If boot succeeds, transition to Idle, reset failure count.
       - start(intervalMs = 30000): Sets interval calling checkAll().
       - stop(): Clears interval.

    2. Write tests in server/pool/__tests__/health-checker.test.ts:
       - Mock DeviceDriver.isHealthy to return true/false.
       - Test healthy device: no restart called.
       - Test 1st failure: restart called after ~5s delay (use fake timers).
       - Test 3rd failure with wipe: cleanup called before boot.
       - Test 4th failure: device goes Offline.
       - Test running device fails: transitions to Error, no restart.
       - Test parallel check: multiple devices checked via Promise.allSettled.
       - Use vi.useFakeTimers() for delay testing.
  </action>

  </verify>
