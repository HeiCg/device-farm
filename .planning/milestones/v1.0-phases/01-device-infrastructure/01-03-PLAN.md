  <behavior>
    - allocate('android') returns an idle Android device when one is available
    - allocate('ios') returns an idle iOS device when one is available
    - allocate('android') returns null when no Android devices are idle
    - Two concurrent allocate('android') calls with one idle device: one gets it, other gets null
    - FIFO: if device-1 became idle before device-2, device-1 is allocated first
    - release(deviceId) transitions device through Cleanup back to Idle
    - getDevices() returns all devices with current state
    - getDevice(id) returns single device info
    - initPool(config) creates and boots all configured devices at startup
  </behavior>
  <action>
    1. Create server/pool/pool-manager.ts:
       - PoolManager class with constructor(config: AppConfig, processTracker: ProcessTracker, logger: pino.Logger).
       - Private devices: Map of string to Device, private drivers: Map of Platform to DeviceDriver.
       - initPool(): For each platform (if enabled), create max_instances devices using the appropriate driver. Call driver.create() then driver.boot(). Register PIDs with processTracker. Transition each device Booting -> Idle. For Android, save clean snapshot after first boot for cleanup use.
       - allocate(platform: Platform): Mutex-protected. Finds first Idle device matching platform (FIFO by insertion order -- Map preserves insertion order). Calls device.allocate(jobId). Returns DeviceInfo or null.
       - release(deviceId: string): Gets device, calls driver.cleanup(emulatorId), transitions Cleanup -> Idle via device.release().
       - getDevices(): Returns DeviceInfo[] for all devices.
       - getDevice(id): Returns single DeviceInfo or null.
       - shutdown(): Shuts down all devices cleanly, kills process groups.

       - Registers onClose hook to call pool.shutdown().

Test FIFO order, concurrent allocation (Promise.all with 2 allocate calls, 1 idle device), release flow, platform filtering. Use async-mutex to verify no double allocation.

<task type="auto" tdd="true">
  <name>Task 2: Process tracker + Orphan reaper</name>
  <files>
    server/pool/process-tracker.ts,
    server/pool/__tests__/process-tracker.test.ts
  </files>
  <behavior>
    - register(deviceId, pid) stores the PID mapping
    - unregister(deviceId) removes the PID mapping
    - killProcess(deviceId) sends SIGTERM to process group (negative pid), then SIGKILL after timeout
    - killProcess for already-dead process (ESRCH) does not throw
    - killAll() kills all tracked process groups
    - scanOrphans() finds emulator processes not in the tracked set
    - reapOrphans() kills orphaned emulator processes found by scanOrphans
  </behavior>
  <action>
    1. Create server/pool/process-tracker.ts:
       - ProcessTracker class with constructor(logger: pino.Logger).
       - Private pids: Map of string to number (deviceId -> pid).
       - register(deviceId, pid): Stores mapping.
       - unregister(deviceId): Removes mapping.
       - killProcess(deviceId): Gets pid, sends process.kill with negative pid and SIGTERM. Sets 5s timeout, then SIGKILL with negative pid if still alive. Catches ESRCH (process already dead). Unregisters after kill.
       - killAll(): Iterates all tracked PIDs, kills each process group. Used during shutdown.
       - scanOrphans(): Runs `ps aux` via execFile (NOT exec) and filters for emulator/qemu processes. Compares against tracked PIDs. Returns list of orphan PIDs. Also scan for orphan simulator processes via `xcrun simctl list devices -j` checking for booted devices not in our registry.
       - reapOrphans(): Calls scanOrphans(), kills each orphan with SIGTERM.
       - startReaper(intervalMs): Sets up periodic interval to call reapOrphans(). Default interval 60s.
       - stop(): Clears the reaper interval.

    2. Write tests in server/pool/__tests__/process-tracker.test.ts:
       - Mock process.kill to verify correct signals and negative PID (process group).
       - Test ESRCH handling (mock kill to throw with code ESRCH).
       - Test register/unregister flow.
       - Mock execFile for scanOrphans tests (simulate ps output with known PIDs).
       - Test killAll iterates all tracked PIDs.
