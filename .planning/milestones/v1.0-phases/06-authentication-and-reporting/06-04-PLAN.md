**login/+page.svelte** -- Validate against a protected endpoint instead of /api/health:

1. Replace the `await fetch('/api/health');` call with `await apiFetch('/admin/keys');` (already imported). The `apiFetch` function will inject the Bearer header from the key we just set via `setApiKey(key)`.
2. IMPORTANT: Wrap the apiFetch call to catch the 401 specifically. The apiFetch 401 handler calls `clearApiKey()` and `window.location.href = '/login'` -- but we are already on /login, so we need to prevent that redirect. Instead, catch any error from apiFetch: if it's a 401 or any error, call `clearApiKey()` and set `errorMsg = 'Invalid API key'`.
3. The corrected flow:
   ```
   setApiKey(key);
   try {
     await apiFetch('/admin/keys');
     window.location.href = '/';
   } catch {
     clearApiKey();
     errorMsg = 'Invalid API key';
   }
   ```
   This works because apiFetch will throw an ApiError on 401. The existing 401 handler in apiFetch redirects to /login -- but since we're already there, the catch block will fire first. To be safe, move the entire try/catch inside the submit handler and ensure `submitting = false` in finally.
