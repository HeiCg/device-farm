  <action>
    1. Create web/src/lib/auth/auth-store.svelte.ts using Svelte 5 runes (follow pattern from web/src/lib/ws/*.svelte.ts):
       - const AUTH_KEY = 'device-farm-api-key'
       - let apiKey = $state<string | null>(typeof localStorage !== 'undefined' ? localStorage.getItem(AUTH_KEY) : null)
       - Export functions: getApiKey(), setApiKey(key), clearApiKey(), isAuthenticated()
       - setApiKey persists to localStorage, clearApiKey removes from localStorage

    2. Modify web/src/lib/api/client.ts:
       - Import getApiKey and clearApiKey from auth-store.svelte
       - In apiFetch, inject Authorization: Bearer <key> header if key exists
       - On 401 response, call clearApiKey() and redirect to /login via window.location.href
       - IMPORTANT: Check if window is defined (SSR safety even though ssr:false, defensive coding)

    3. Create web/src/routes/login/+page.svelte:
       - Simple centered card with:
         - Title: "Device Farm" and subtitle: "Enter your API key to continue"
         - Text input for API key (type="password" for security)
         - Submit button
         - Error message area
       - On submit: call setApiKey(inputValue), then try a lightweight API call (GET /api/health) to validate
       - If health check succeeds: redirect to / (dashboard)
       - If health check fails with 401: show "Invalid API key" error, call clearApiKey()
       - Style with Tailwind: bg-white rounded-lg shadow-lg p-8, max-w-md mx-auto, mt-32

    4. Modify web/src/routes/+layout.svelte:
       - Import isAuthenticated from auth-store
       - Import { page } from '$app/state' (Svelte 5 pattern per Phase 05 decision)
       - Add auth gate: if not authenticated AND not on /login page, redirect to /login
       - Use $effect to reactively watch auth state changes
       - When on /login page, render children without Nav (login page gets its own minimal layout)
       - When authenticated, render full layout with Nav
       - IMPORTANT: Avoid redirect loop -- /login page must render even when not authenticated
  </action>
  <verify>
    <automated>cd web && npx svelte-check --threshold error 2>&1 | tail -5</automated>
  </verify>
  <done>
    - Auth store manages API key in $state + localStorage
    - API client injects Bearer header on all requests
    - 401 responses trigger redirect to /login
    - Login page validates key against /api/health
    - Layout redirects unauthenticated users to /login (except when already on /login)
  </done>
