    - Parser handles ANSI color codes (strips them before matching)
    - Parser handles shard prefix lines like "[shard 1] Running flow ..."
    - Unrecognized lines are collected in rawOutput
    - After processing all lines, getSummary() returns { total, passed, failed, skipped } computed from flow results

       - `QueuedJob`: { id: string, platform: Platform, metadata: Record<string, unknown>, files: Array<{ filename: string, content: string }>, createdAt: Date }
       - `JobStep`: { flowName: string, command: string | null, status: 'passed' | 'failed' | 'skipped' | 'running', durationMs: number | null }
       - `JobSummary`: { total: number, passed: number, failed: number, skipped: number }
       - `ParserCallbacks`: { onFlowStart(name: string): void, onCommandStatus(command: string, status: string): void, onFlowResult(flow: string, status: string, durationMs: number): void, onSummary(passed: number, total: number): void }

       - Import strip-ansi (ESM: `import stripAnsi from 'strip-ansi'`)

         - FLOW_START: `/^(?:\[shard \d+\] )?Running flow (.+)$/`
         - COMMAND_STATUS: `/^(?:\[shard \d+\] )?(.+?) (COMPLETED|FAILED|SKIPPED|RUNNING)$/`
         - FLOW_RESULT: `/^(?:\[shard \d+\] )?\[(Passed|Failed|Canceled)\] (.+?) \((\d+)s\)$/`
         - SUITE_SUMMARY: `/^(\d+)\/(\d+) Flows? (Passed|Failed)/`
       - Class MaestroParser with:
         - `parseLine(rawLine: string): void` — strip ANSI, trim, match patterns in priority order (SUITE_SUMMARY > FLOW_RESULT > COMMAND_STATUS > FLOW_START), collect unmatched in rawOutput array
         - Internal tracking: currentFlow, flowResults Map<string, 'passed'|'failed'|'skipped'>, steps array
         - `getSteps(): JobStep[]` — return accumulated steps
         - `getSummary(): JobSummary` — compute from flowResults (or from suite summary line if available)
         - `getRawOutput(): string` — join rawOutput with newlines
       - Parser should NOT use readline (that's the executor's job) — just process individual lines

       - Test command status detection (COMPLETED, FAILED, SKIPPED)
       - Test flow result detection with duration parsing
       - Test suite summary parsing
       - Test ANSI code stripping (wrap test input in ANSI escapes)
       - Test unrecognized lines go to rawOutput
       - Test getSummary() aggregation
       - Test empty input produces zero summary

  <behavior>
    - enqueue(job) adds job to the end of the queue
    - dequeue() removes and returns the first job (FIFO)
    - dequeue() returns undefined when queue is empty
    - peek() returns the first job without removing it
    - size() returns current queue length
    - isEmpty() returns true when queue has no jobs
    - remove(jobId) removes a specific job by ID and returns it (for cancel)
    - isFull(maxSize) returns true when size >= maxSize
  </behavior>
  <action>
