<task type="auto" tdd="true">
  <name>Task 2: Cursor pagination helpers, metadata filter builder, and validation schemas with tests</name>
  <files>server/api/pagination.ts, server/api/validation.ts, server/api/__tests__/pagination.test.ts</files>
  <behavior>
    - encodeCursor({createdAt, id}) produces base64url string
    - decodeCursor(cursor) returns {createdAt: Date, id: string}
    - decodeCursor on invalid input throws clear error
    - buildMetadataFilters(query) extracts metadata.* params and returns SQL conditions
    - buildCursorWhere(cursor) returns Drizzle WHERE clause for (createdAt, id) composite
    - Validation schemas accept valid inputs and reject invalid ones
  </behavior>
  <action>
    1. Create `server/api/pagination.ts`:
       - `encodeCursor(item: { createdAt: Date, id: string }): string` — JSON.stringify + Buffer base64url
       - `decodeCursor(cursor: string): { createdAt: Date, id: string }` — base64url decode + JSON.parse, wrap in try/catch with clear error
       - `buildCursorWhere(cursor: string, table: typeof jobs)` — returns Drizzle SQL condition: `(createdAt < cursorDate) OR (createdAt = cursorDate AND id < cursorId)` using drizzle-orm operators (lt, eq, and, or)
       - `buildMetadataFilters(query: Record<string, string>)` — iterate entries, for keys starting with "metadata.", build `sql\`${jobs.metadata}->>'${jsonPath}' = ${value}\`` conditions using drizzle-orm sql template
       - `buildPaginatedResponse<T>(items: T[], limit: number, encodeFn: (item: T) => string)` — if items.length > limit, pop last, return { data: items, cursor: encodeFn(last), hasMore: true }, else { data: items, cursor: null, hasMore: false }

    2. Create `server/api/validation.ts`:
       - Import z from 'zod'
       - `listJobsQuerySchema`: z.object({ cursor: z.string().optional(), limit: z.coerce.number().int().min(1).max(100).default(20), status: z.enum(['queued','running','passed','failed','cancelled','timeout']).optional(), platform: z.enum(['android','ios']).optional() })
         - Note: metadata.* params handled separately (dynamic keys can't be in fixed schema)
       - `createJobSchema`: z.object({ platform: z.enum(['android', 'ios']) }) — for the platform field in multipart
       - Export schemas

    3. Write tests in `server/api/__tests__/pagination.test.ts`:
       - Test: encodeCursor -> decodeCursor roundtrip preserves data
       - Test: decodeCursor on garbage input throws
       - Test: buildMetadataFilters extracts metadata.* keys correctly
       - Test: buildMetadataFilters ignores non-metadata keys
       - Test: buildPaginatedResponse with hasMore=true (items > limit)
       - Test: buildPaginatedResponse with hasMore=false (items <= limit)
       - Test: listJobsQuerySchema validates and coerces correctly
       - Test: listJobsQuerySchema rejects invalid limit
  </action>
