  <name>Task 1: API clients, shared components, and utility functions</name>
  <files>web/src/lib/api/jobs.ts, web/src/lib/api/health.ts, web/src/lib/components/shared/StatusBadge.svelte, web/src/lib/components/shared/Pagination.svelte, web/src/lib/components/shared/Filters.svelte, web/src/lib/components/jobs/JobCard.svelte, web/src/lib/utils/format.ts</files>
  <action>
1. **web/src/lib/api/jobs.ts**: Typed job API functions:
   - `listJobs(params?: { status?: string; platform?: string; cursor?: string })`: Builds URLSearchParams, calls apiFetch for GET /jobs, returns `PaginatedResponse<Job>`
   - `getJob(id: string)`: GET /jobs/:id, returns Job with steps
   - `cancelJob(id: string)`: DELETE /jobs/:id
   - `getJobLogs(id: string)`: GET /jobs/:id/logs, returns `{ logs: string }`
   - `getJobArtifacts(id: string)`: GET /jobs/:id/artifacts, returns `Artifact[]`

2. **web/src/lib/api/health.ts**: `getHealth()`: GET /health, returns HealthResponse.

3. **web/src/lib/utils/format.ts**: Utility functions using date-fns:
   - `formatRelativeTime(date: string)`: Returns "2 minutes ago" style using `formatDistanceToNow`
   - `formatDuration(startedAt: string | null, finishedAt: string | null)`: Returns "1m 23s" or "--"
   - `statusColor(status: string)`: Maps status to Tailwind color classes (passed->green, failed->red, running->blue, queued->yellow, cancelled->gray, timeout->orange)
   - `platformLabel(platform: string)`: 'android' -> 'Android', 'ios' -> 'iOS'

4. **web/src/lib/components/shared/StatusBadge.svelte**: Takes `status` prop. Renders a pill-shaped badge with appropriate background color using statusColor() and the status text. Use `$props()` for props.

5. **web/src/lib/components/shared/Filters.svelte**: Filter bar with:
   - Status dropdown (All, Queued, Running, Passed, Failed, Cancelled, Timeout)
   - Platform dropdown (All, Android, iOS)
   - Dispatches `onchange` callback with `{ status, platform }` when any filter changes
   - Use Tailwind: flex row, gap-3, select elements with basic styling

6. **web/src/lib/components/shared/Pagination.svelte**: "Load More" button. Props: `hasMore`, `loading`, callback `onloadmore`. Shows button only when hasMore is true. Shows spinner/text when loading.

7. **web/src/lib/components/jobs/JobCard.svelte**: Card for a single job. Props: `job: Job`. Displays:
   - StatusBadge for job.status
   - Platform label
   - Job ID (truncated first 8 chars)
   - Relative time (createdAt)
   - Duration if finishedAt exists
   - Click navigates to /jobs/{id} using `<a>` tag
   - Tailwind: bg-white rounded-lg shadow-sm p-4 hover:shadow-md transition-shadow border border-gray-200
