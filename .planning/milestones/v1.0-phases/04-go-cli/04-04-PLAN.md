    PREREQUISITE: cli/go.mod must exist (created by Plan 01 Task 1). If running in parallel, wait for module init.

    1. Create `cli/internal/output/table.go`:
       - PrintTable(w io.Writer, headers []string, rows [][]string) using tabwriter with minwidth=0, tabwidth=8, padding=2, padchar=' '
       - Print headers in uppercase, tab-separated, then newline
       - Print each row tab-separated, then newline
       - Flush tabwriter at end
       - No box-drawing characters -- clean kubectl-style aligned columns

    2. Create `cli/internal/output/table_test.go`:
       - TestPrintTableBasic: 2 headers, 3 rows, verify output has aligned columns
       - TestPrintTableEmpty: headers only, no rows, verify headers still printed
       - TestPrintTableSingleColumn: single column renders without extra tabs
       - TestPrintTableAlignment: columns with varying widths are properly aligned (check that shorter values are padded)
       - Use bytes.Buffer to capture output, verify with strings.Contains or exact match

    3. Create `cli/internal/output/color.go`:
       - StatusColor(status string) *color.Color mapping:
         - passed -> color.FgGreen
         - failed -> color.FgRed
         - running -> color.FgCyan
         - queued -> color.FgYellow
         - cancelled -> color.FgYellow
         - timeout -> color.FgRed
         - error -> color.FgRed
         - idle -> color.FgGreen
         - default -> color.Reset (no color)

    4. Create `cli/internal/output/symbols.go`:
       - StatusSymbol(status string, isTTY bool) string
       - TTY symbols: passed="checkmark", failed="X", pending="circle", running="filled-circle", warning="triangle"
       - Non-TTY: passed="[PASS]", failed="[FAIL]", pending="[PEND]", running="[RUN]", warning="[WARN]"
       - Mapping: passed->checkmark, failed->X, running->filled-circle, queued->circle, cancelled->warning, timeout->X, error->X, idle->checkmark

    5. Create `cli/internal/output/json.go`:
       - PrintJSON(w io.Writer, v any) error
       - Use json.NewEncoder with SetIndent("", "  ") for pretty output
       - Return encoder error if any
