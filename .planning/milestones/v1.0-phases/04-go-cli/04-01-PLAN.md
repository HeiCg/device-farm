From server/streaming/types.ts:
```typescript
export type WsMessageType = 'log' | 'step' | 'metrics' | 'status' | 'logcat';
export interface JobMessage { type: WsMessageType; data: unknown; timestamp: string; }
export interface LogData { line: string; stream: 'stdout' | 'stderr'; }
export interface StepData { flowName: string; command: string | null; status: string; durationMs: number | null; }
export interface StatusData { status: 'running' | 'passed' | 'failed' | 'cancelled' | 'timeout'; }
```

Server API endpoints (from server/api/routes.ts):
- POST /api/jobs - multipart (files + platform + metadata) -> 201 + job object
- GET /api/jobs - cursor pagination (cursor, limit, status, platform query params)
- GET /api/jobs/:id - job details with steps
- GET /api/jobs/:id/logs - { logs: string }
- GET /api/jobs/:id/artifacts - artifact list
- GET /api/jobs/:id/artifacts/:artifactId - file download
- DELETE /api/jobs/:id - cancel job -> { status: 'cancelled' }
- GET /api/devices - device list
- GET /api/health - server health
- All errors: RFC 7807 { type, title, status, detail, instance }

    PREREQUISITE: Go must be installed. Check `go version`. If not available, install via `brew install go` (macOS). Require Go 1.22+.

    1. Initialize Go module at `cli/` directory:
       - `go mod init github.com/device-farm/cli`
       - Install deps: `go get github.com/spf13/cobra@latest github.com/coder/websocket@latest go.yaml.in/yaml/v3@latest github.com/fatih/color@latest golang.org/x/term@latest`

    2. Create `cli/internal/config/config.go`:
       - Config struct with ServerURL, APIKey, Defaults (Platform, Timeout, Format) using yaml struct tags
       - configPath() returns ~/.device-farm.yaml
       - Load() reads YAML, returns empty Config if file not found
       - Save() writes YAML with 0600 permissions
       - Get(key string) returns value using dot notation (e.g., "defaults.platform") via reflect or switch
       - Set(key, value string) sets value using dot notation, creates file if needed
       - ListAll() returns map[string]string of all config values with API key masked (show last 4 chars: `df_key_***xxxx`)

    3. Create `cli/internal/config/resolve.go`:
       - ResolveServerURL(flagValue string) string -- priority: flag > DEVICE_FARM_URL env > config > "http://localhost:3000"
       - ResolveAPIKey(flagValue string) string -- priority: flag > DEVICE_FARM_API_KEY env > config > ""
       - ResolvePlatform(flagValue string) string -- priority: flag > DEVICE_FARM_PLATFORM env > config > ""

    4. Create `cli/internal/client/client.go`:
       - Client struct with BaseURL, APIKey, HTTPClient fields
       - NewClient(baseURL, apiKey string) *Client -- creates client with 30s timeout
       - ProblemDetail struct matching RFC 7807 (Type, Title, Status, Detail, Instance)
       - do(ctx, method, path string, body io.Reader, contentType string) (*http.Response, error) -- adds auth header if APIKey set, parses 4xx/5xx into ProblemDetail error
       - ExitError type with Code int and Error() string -- used by commands to propagate exit codes

    5. Create `cli/cmd/root.go`:
       - Root cobra.Command: Use "device-farm", Short description
       - Persistent flags: --server (string), --api-key (string), --json (bool), --no-color (bool)
       - PersistentPreRun: if noColor, set color.NoColor = true; detect TTY via term.IsTerminal
       - Export package-level vars: ServerFlag, APIKeyFlag, JSONOutput, NoColor, IsTTY
       - Execute() function returning error

    6. Create `cli/main.go`:
       - Call cmd.Execute(), check for ExitError to get code, os.Exit appropriately
       - Exit 2 for non-ExitError errors (infrastructure failures)

    7. Create `cli/Makefile`:
       - build: `go build -o bin/device-farm .`
       - test: `go test ./... -short -count=1`
       - test-race: `go test ./... -v -count=1 -race`
       - install: `go install .`
       - clean: `rm -rf bin/`

    8. Create `cli/internal/config/config_test.go`:
       - TestLoadNonExistent: returns empty config
       - TestSaveAndLoad: roundtrip save/load
       - TestSetGet: set dot-notation key, get returns value
       - TestListAll: masks API key
       - TestFilePermissions: saved file has 0600
       - Use t.TempDir() for test isolation

    9. Create `cli/internal/client/client_test.go`:
       - TestAuthHeader: mock server (httptest), verify Authorization: Bearer header sent
       - TestNoAuthHeader: no API key, no header sent
       - TestRFC7807Error: mock server returns problem+json, client returns readable error
       - TestServerUnreachable: bad URL returns error with exit code 2

    10. Create `cli/cmd/root_test.go`:
