<task type="auto">
  <name>Task 2: Replace recordings table with unified artifacts table and update config</name>
  <files>server/db/schema.ts, server/config/schema.ts</files>
  <action>
1. In `server/db/schema.ts`:
   - Add `artifactTypeEnum` pgEnum: `['video', 'screenshot', 'logcat', 'memory', 'log']`
   - Replace the `recordings` table with a new `artifacts` table:
     ```
     id: uuid PK default gen_random_uuid()
     jobId: uuid NOT NULL references jobs.id with onDelete: 'cascade'
     type: artifactTypeEnum NOT NULL
     filePath: varchar(1024) NOT NULL
     fileName: varchar(255) NOT NULL
     mimeType: varchar(128) NOT NULL
     fileSizeBytes: bigint({ mode: 'number' }) nullable
     compressed: boolean NOT NULL default false
     compressedAt: timestamp with timezone nullable
     createdAt: timestamp with timezone NOT NULL defaultNow()
     ```
   - Add indexes: `artifacts_job_id_idx` on jobId, `artifacts_created_at_idx` on createdAt, `artifacts_type_idx` on type
   - Remove the old `recordings` table export entirely
   - Keep the `index` import from `drizzle-orm/pg-core`

2. In `server/config/schema.ts`:
   - Rename `recordingsSchema` to `artifactsSchema` and update the path default from `'./recordings'` to `'./storage/artifacts'`
   - Keep all existing fields: `path`, `retention_days` (default 30), `compress_after_days` (default 7), `format` (mp4), `max_storage_gb` (default 50)
   - Update `storageSchema` to use `artifacts` key instead of `recordings`
   - Update `logsSchema` path default to `'./storage/logs'`
   - Ensure `AppConfig` type reflects the new `storage.artifacts` shape

3. Update any imports in `server/api/routes.ts` if it references `recordings` (the GET /jobs/:id/recording route is a stub returning 404, keep it as-is for now -- it will be replaced in Plan 05).
