  <name>Task 1: LogcatService and MemoryService for Android data capture</name>
  <files>server/artifacts/logcat-service.ts, server/artifacts/memory-service.ts, server/artifacts/__tests__/logcat-service.test.ts, server/artifacts/__tests__/memory-service.test.ts</files>
  <behavior>
    LogcatService:
    - start(jobKey, deviceId, outputPath, onLine) spawns adb logcat via spawn (no shell), writes to file and calls onLine per line
    - stop(jobKey) kills logcat process, closes file stream
    - PID registered in ProcessTracker

    MemoryService:
    - startSampling(jobKey, deviceId, intervalMs, onSample) runs periodic adb dumpsys meminfo via execFile (no shell), parses totalPss/nativeHeap/javaHeap
    - stopSampling(jobKey) clears interval, returns accumulated samples
    - writeSamples writes JSON array to file
    - Handles missing package name gracefully
  </behavior>
  <action>
1. Create `server/artifacts/logcat-service.ts`:
   - Import `spawn` from `node:child_process` (safe, no shell invocation)
   - Constructor: `(logger: pino.Logger, processTracker?: ProcessTracker, spawnFn?)` -- injectable spawn for testing
   - `start(jobKey: string, deviceId: string, outputPath: string, onLine: (line: string) => void): void`
     - Use spawn('adb', ['-s', deviceId, 'logcat', '-v', 'time']) with stdio ['ignore', 'pipe', 'ignore']
     - Create readline.createInterface on child.stdout
     - On each line: write to createWriteStream(outputPath, { flags: 'a' }) and call onLine(line)
     - Register PID in processTracker
     - Store in Map with child process and file stream references
   - `stop(jobKey: string): void` -- kill process (SIGTERM), close file stream, unregister PID
   - Note: Only works for Android. For iOS, logcat is not available -- this is Android-only per REAL-06.

2. Create `server/artifacts/memory-service.ts`:
   - Import `execFile as nodeExecFile` from `node:child_process` and `promisify` (safe, no shell)
   - Constructor: `(logger: pino.Logger, execFileFn?)` -- injectable execFile
   - `startSampling(jobKey: string, deviceId: string, intervalMs: number, onSample: (metrics: MetricsData) => void): void`
     - Set up setInterval that runs execFile('adb', ['-s', deviceId, 'shell', 'dumpsys', 'meminfo', '-c'])
     - Parse compact output: look for lines with proc,total for totalPss; Native Heap and Dalvik Heap for heap sizes
     - Accumulate samples in array, call onSample with each parsed result
     - Store interval handle and samples array in Map
   - `stopSampling(jobKey: string): { samples: MetricsData[] }` -- clear interval, return accumulated samples
   - `writeSamples(outputPath: string, samples: MetricsData[]): Promise<void>` -- writeFile with JSON.stringify(samples, null, 2)

3. Write tests FIRST for both services using injectable mocks.

For logcat tests:
- start() calls spawn('adb', [...]) with correct args (no shell flag)
- Lines from stdout are written to file AND forwarded to callback
- stop() kills process and closes stream

For memory tests:
- startSampling() sets up interval that calls execFile('adb', [...])
- Parses dumpsys compact output correctly (provide sample output string in test)
- stopSampling() clears interval and returns accumulated samples
- writeSamples() writes JSON to file
  </action>

   - Type FrameHandler = (frame: Buffer) => void

   - For Android: dynamically import @device-stream/android and create stream instance
