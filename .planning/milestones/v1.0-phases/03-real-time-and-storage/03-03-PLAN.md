<task type="auto" tdd="true">
  <name>Task 1: RecordingService -- ffmpeg pipe recording lifecycle</name>
  <files>server/artifacts/recording-service.ts, server/artifacts/__tests__/recording-service.test.ts</files>
  <behavior>
    - startRecording(jobId, outputPath) spawns ffmpeg with image2pipe input via node:child_process spawn (no shell), returns writable stdin stream
    - stopRecording(jobId) closes stdin, awaits ffmpeg exit, returns void
    - stopRecording on unknown jobId is a no-op (idempotent)
    - killRecording(jobId) sends SIGTERM to ffmpeg process (for cancel/timeout)
    - ffmpeg PID is registered in ProcessTracker on start, unregistered on stop
    - isRecording(jobId) returns boolean
  </behavior>
  <action>
Create `server/artifacts/recording-service.ts`:
- Import `spawn` from `node:child_process` (NOT exec -- spawn is safe, does not invoke shell)
- Constructor takes `logger: pino.Logger` and optional `processTracker: ProcessTracker` and optional `spawnFn` for testability (same injectable pattern as ProcessTracker uses for execFile)
- `startRecording(jobId: string, outputPath: string): Writable`:
  Uses spawn (not exec) with array args: `['-y', '-f', 'image2pipe', '-framerate', '10', '-i', 'pipe:0', '-c:v', 'libx264', '-preset', 'ultrafast', '-crf', '28', '-pix_fmt', 'yuv420p', '-movflags', '+faststart', outputPath]`
  stdio: `['pipe', 'ignore', 'pipe']`. Spawn with `detached: true` for process group kill.
  Register PID in processTracker. Store in internal Map. Return ffmpeg.stdin.
- `stopRecording(jobId: string): Promise<void>` -- close stdin (.end()), await process exit event, unregister PID, delete from map. If jobId not found, return silently.
- `killRecording(jobId: string): void` -- kill process group (process.kill(-pid, 'SIGTERM')), with try/catch for ESRCH.
- `isRecording(jobId: string): boolean`

Write tests FIRST (inject mock spawn function):
- Test startRecording calls spawn with correct args (no shell)
- Test stopRecording closes stdin and awaits exit
- Test stopRecording on unknown jobId is no-op
- Test killRecording sends SIGTERM to process group
- Test PID registration/unregistration with mock ProcessTracker
  </action>
