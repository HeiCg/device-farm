  <behavior>
    - emit(jobId, message) stores message in per-job ring buffer and emits to listeners
    - subscribe(jobId, handler) replays buffered messages then streams live events; returns unsubscribe function
    - Ring buffer caps at MAX_BUFFER (200) messages per job -- oldest dropped when full
    - cleanup(jobId) removes buffer and all listeners for that job
    - Multiple subscribers receive same messages independently
    - Unsubscribe stops receiving new messages but does not affect other subscribers
    - After cleanup, new subscribe gets empty replay
  </behavior>
  <action>
Create `server/streaming/job-broadcaster.ts`:
- Uses Node.js `EventEmitter` internally (existing pattern in project)
- `emit(jobId: string, message: JobMessage): void` -- push to ring buffer, emit event
- `subscribe(jobId: string, handler: (msg: JobMessage) => void): () => void` -- replay buffer, attach listener, return cleanup function
- `cleanup(jobId: string): void` -- delete buffer, removeAllListeners for that job

  <action>
Create `server/streaming/websocket-plugin.ts` as a Fastify plugin:

1. Register `@fastify/websocket` (import websocket from '@fastify/websocket')
2. Create and decorate `fastify.jobBroadcaster` as a new JobBroadcaster instance
3. Define route `GET /ws/jobs/:id` with `{ websocket: true }`:
   - Extract jobId from `req.params`
   - Subscribe to broadcaster: `const unsub = fastify.jobBroadcaster.subscribe(jobId, handler)`
   - Handler sends JSON.stringify(msg) to socket if `socket.readyState === 1` (WebSocket.OPEN)
   - On socket `close` event: call unsub()
   - On socket `error` event: call unsub() (prevent memory leak per RESEARCH pitfall 2)
   - CRITICAL: Attach socket.on handlers SYNCHRONOUSLY (per @fastify/websocket docs -- async setup drops messages)
4. Implement ping/pong heartbeat:
   - Set up interval (30s) to send `socket.ping()` to each connected client
   - Track `isAlive` flag per socket, set false before ping, set true on pong
   - Terminate sockets that don't respond to ping within interval
   - Clear interval on socket close
5. Add TypeScript augmentation for Fastify instance:
   ```typescript
   declare module 'fastify' {
     interface FastifyInstance {
       jobBroadcaster: JobBroadcaster;
     }
   }
   ```
6. Export as default using `fp()` with name `'websocket-plugin'` and dependencies `['config-plugin']`

NOTE: The device preview route (`/ws/devices/:id/preview`) will be added in Plan 05 after device-stream integration. This plugin only handles job event streaming.
