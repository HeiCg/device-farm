<task type="auto" tdd="true">
  <name>Task 1: Compression, retention, and disk pressure tasks</name>
  <files>server/lifecycle/compression-task.ts, server/lifecycle/retention-task.ts, server/lifecycle/disk-pressure-task.ts, server/lifecycle/__tests__/compression-task.test.ts, server/lifecycle/__tests__/retention-task.test.ts, server/lifecycle/__tests__/disk-pressure-task.test.ts</files>
  <behavior>
    Compression:
    - Finds video artifacts where compressed=false AND createdAt < (now - compress_after_days)
    - Re-encodes each with ffmpeg (slow preset, CRF 35, scale to 720p max, no audio)
    - Replaces original file, updates compressed=true, compressedAt, fileSizeBytes in DB
    - Returns { compressed: number, savedBytes: number }

    Retention:
    - Finds artifacts where createdAt < (now - retention_days)
    - Deletes files from filesystem, then deletes DB rows
    - Returns { deleted: number, freedBytes: number }

    Disk pressure:
    - Sums fileSizeBytes from artifacts table
    - If total > max_storage_gb * 1024^3, deletes oldest artifacts until under limit
    - Returns { deleted: number, freedBytes: number, currentUsageBytes: number }
  </behavior>
  <action>
1. Create `server/lifecycle/compression-task.ts`:
   - `runCompressionTask(db: Database, config: AppConfig, logger: pino.Logger): Promise<CompressionResult>`
   - Query: `SELECT * FROM artifacts WHERE type='video' AND compressed=false AND createdAt < (now - compress_after_days)`
   - For each: spawn ffmpeg with `-y -i {filePath} -c:v libx264 -preset slow -crf 35 -vf scale=-2:720 -an {tempPath}`
   - Await ffmpeg exit. If success: rename temp to original, stat for new size, update DB row (compressed=true, compressedAt=now, fileSizeBytes=newSize)
   - If ffmpeg fails: log error, skip that file, continue
   - Use async-mutex to prevent overlapping runs (per RESEARCH pitfall 7)
   - Return `{ compressed, savedBytes }`

2. Create `server/lifecycle/retention-task.ts`:
   - `runRetentionTask(db: Database, config: AppConfig, logger: pino.Logger): Promise<RetentionResult>`
   - Query: `SELECT * FROM artifacts WHERE createdAt < (now - retention_days)` ordered by createdAt ASC
   - For each: `rm(filePath, { force: true })`, then delete DB row
   - Group by jobId -- after deleting all artifacts for a job, also clean up the empty job directory
   - Return `{ deleted, freedBytes }`

3. Create `server/lifecycle/disk-pressure-task.ts`:
   - `runDiskPressureTask(db: Database, config: AppConfig, logger: pino.Logger): Promise<DiskPressureResult>`
   - Query: `SELECT SUM(file_size_bytes) as total FROM artifacts` (use DB aggregation per RESEARCH pitfall 6)
   - If total > max_storage_gb * 1024 * 1024 * 1024:
     - Query oldest artifacts: `SELECT * FROM artifacts ORDER BY createdAt ASC`
     - Delete one by one until total is under limit
   - Return `{ deleted, freedBytes, currentUsageBytes }`

4. Write tests FIRST for all three tasks:
   - Compression: mock DB returning old video artifacts, mock spawn returning success, verify DB update
   - Retention: mock DB returning expired artifacts, verify rm called, verify DB delete
   - Disk pressure: mock DB returning total over limit, verify oldest deleted first, stops when under limit
   - All: verify error handling (individual failures don't crash the task)
